# Claim-level grounding

KnowledgeHub RAG v1.1 separates text generation from source attribution.

## Why

Small local instruction models are much better at generating normal text than at consistently producing correct citation syntax.

Therefore citations are no longer generated by the LLM.

## Pipeline

```text
Question
  -> hybrid chunk retrieval
  -> evidence context
  -> local LLM generates plain text
  -> split answer into claims
  -> embed every claim
  -> embed retrieved source excerpts
  -> semantic + lexical claim/source comparison
  -> assign best supporting source
  -> remove unsupported claims
  -> add citations automatically
```

## Claim grounding score

For every generated claim and every retrieved source:

```text
0.78 * claim/source semantic similarity
+ 0.17 * lexical overlap
+ 0.05 * original retrieval score
```

A claim is accepted only when:

- grounding score >= 0.43;
- semantic similarity >= 0.34.

## Coverage

```text
grounding_coverage =
grounded_claims / generated_claims
```

If fewer than 50% of generated claims can be grounded, the whole LLM answer is rejected and KnowledgeHub returns the extractive fallback.

If at least 50% can be grounded, unsupported claims are removed and only verified claims are shown.

## Result

The user receives:

- a generated answer;
- citations added by KnowledgeHub, not by the LLM;
- grounding coverage;
- a claim-level audit;
- grounding score for every accepted claim;
- source excerpts used as evidence.
